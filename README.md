## Incluye
- Página responsive y mobile-first.
- Menú superior con botones reales.
- Botón de compra conectado a Hotmart en header, hero, contenido, modal, footer y barra fija móvil.

- Dinosaurios integrados como parte del lenguaje visual.
- No requiere frameworks ni instalación: HTML + CSS + JavaScript puro.

## Publicar en GitHub Pages
1. Sube `index.html`, `style.css`, `script.js` y la carpeta `assets` al repositorio.
2. En GitHub entra a Settings → Pages.
3. Selecciona la rama donde están estos archivos y la carpeta `/root`.
4. Guarda y espera a que GitHub publique.
