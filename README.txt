# Página de donaciones — A tu ritmo, contigo

## Archivos
- `index.html` — estructura de la página.
- `styles.css` — diseño responsive y animaciones.
- `script.js` — botones, valor personalizado y Google Analytics.
- `campaña.jpg` — debes colocar aquí la imagen original de campaña, sin editarla.

## Publicación
1. Sube los archivos al repositorio de GitHub Pages.
2. Pon la imagen original de campaña en la misma carpeta y llámala exactamente `campaña.jpg`.
3. Activa GitHub Pages desde Settings > Pages si todavía no está activo.

## Medición
La página usa el ID de Google Analytics `G-30QGR4ZMD5`.
El evento principal es `donation_button_click`, con el valor de la donación enviado como parámetro.

## Importante
El botón de cada aporte lleva al canal:
https://fundacion.cardioinfantil.org/donar.html
y agrega el valor como parámetro `monto`.

La información de privacidad mostrada en la página es un aviso breve. Si la organización tiene un texto legal oficial de tratamiento de datos, conviene sustituir ese aviso por el texto aprobado oficialmente.
